# HA Editor

A lightweight alternative to the Studio Code Server add-on: a file tree and the Monaco editor for your Home Assistant configuration, with nothing else.

- Syntax highlighting and YAML checks for Home Assistant tags (`!include`, `!secret`, …)
- Home Assistant and ESPHome file icons
- Find and replace, plus search across all configuration files
- Safe saves that detect changes made by other tools
- Opens from the sidebar through Home Assistant ingress, with no extra port or login
